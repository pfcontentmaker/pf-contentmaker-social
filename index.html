PF.Contentmaker Social

A private social media management tool for a single operator.

What it does

PF.Contentmaker Social collects performance metrics from, and publishes content to, social media accounts owned and operated by Felipe Puerta, an independent content producer. Metrics from each account are recorded over time so that content decisions can be based on how that account actually performs.

Scope

  • It is used only on accounts the operator owns. It is not offered to other people.
  • It has no user registration, no public interface and no commercial offering.
  • Metrics and access tokens are stored locally on the operator’s own computer.
  • AI-generated or AI-altered content published through it is labelled using the platform’s own disclosure controls.

TikTok integration

Through TikTok Login Kit, an account owned by the operator can authorize the App to read its profile information and statistics (followers, following, likes, video count) and its own list of public videos. Publishing, where enabled, uses TikTok’s Content Posting API. No data belonging to any other TikTok user is accessed.
